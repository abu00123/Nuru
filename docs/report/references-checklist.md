## Rules to keep the list correct

1. Insert every citation with the Zotero plugin; never type one by hand. Zotero then adds a/b suffixes and builds the list automatically.
2. Do not add anything to the reference list manually. If a source is in the list but not cited, or cited but missing, something was typed by hand.
3. After adding the Mahama page, UNHCR will have two "n.d." sources. Zotero will relabel them "n.d.-a" and "n.d.-b"; this is correct.
4. **UNHCR abbreviation.** Zotero prints "United Nations High Commissioner for Refugees" in full every time. APA allows writing it in full once with "[UNHCR]" and abbreviating after that. To do this in Word: on the first citation, leave it in full and add "[UNHCR]" in the Zotero dialog's suffix if needed; for every later UNHCR citation, open the citation in the Zotero dialog, tick **Suppress Author**, and type **UNHCR,** in the **Prefix** box. The result reads "(UNHCR, 2022)".
5. Sources added in the first round but not used in the final text (e.g., Venkatesh et al., 2003; Fogg et al., 2003) can stay in Zotero. They will not appear in the list unless cited.
6. Before submitting, compare the generated reference list with this table: it should contain exactly the sources above.
